# Prachi ❤️ — Birthday Surprise

A mobile-first romantic birthday microsite made for **Prachi**, from **Jayant**.

## Publish on GitHub Pages

1. Create a new **public** GitHub repository, for example:
   `prachi-birthday`
2. Upload **all files and folders** from this project. Keep the `assets` folder.
3. On GitHub open:
   **Settings → Pages**
4. Under **Build and deployment**, choose:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/ (root)**
5. Save and wait for GitHub Pages to publish.
6. Your website will look like:
   `https://YOUR-USERNAME.github.io/prachi-birthday/`

## QR Code

After the GitHub Pages URL works, use any QR generator and paste the exact URL.

**Tip:** Test the QR code from a second phone/mobile data before giving it to Prachi.
